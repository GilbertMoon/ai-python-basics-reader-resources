# Exercises

각 Chapter의 추가 연습문제와 별도 실습 파일을 관리하기 위한 폴더입니다.

도서 본문의 **따라해 보기, 바꿔 보기, 스스로 해결하기, Chapter Check**는 현재 각 Chapter HTML 안에 포함되어 있습니다. 별도 파일이 필요한 연습문제만 이 폴더에 추가합니다.

추가 시 폴더 이름은 예제 코드와 같은 `chapterXX` 형식을 사용합니다.

```text
exercises/
├── chapter04/
├── chapter05/
├── ...
└── chapter24/
```

권장 파일 이름 예:

```text
exercises/chapter10/practice10_01.py
exercises/chapter14/chapter_check14_02.py
```

운영 원칙:

- 해당 Chapter에서 배운 문법 범위 안에서 해결할 수 있도록 작성합니다.
- 정답 코드를 바로 제공하기보다 힌트 → 수정 → 검증 흐름을 우선합니다.
- 별도 데이터가 필요하면 `data/chapterXX/`를 사용합니다.
