# Data

도서 실습에서 사용하는 CSV와 텍스트 데이터를 Chapter별로 관리합니다.

현재 주요 데이터:

```text
data/
├── chapter16/    # 텍스트 파일과 CSV 읽기·쓰기
├── chapter17/    # 안전한 파일 읽기 실습
├── chapter21/    # pandas 첫 데이터 점검
├── chapter22/    # 판매 데이터 분석
├── chapter23/    # 개인 지출 프로젝트 검산
└── chapter24/    # 주문 데이터 종합 분석 프로젝트
```

운영 원칙:

- 가능하면 도서용으로 직접 제작한 데이터 또는 재배포 가능한 데이터만 사용합니다.
- 본문에서 제시하는 행 수, 열 이름, 결측값, 합계와 실제 파일 내용을 일치시킵니다.
- 분석용 데이터는 학습자가 손으로 일부 결과를 검산할 수 있을 정도의 크기로 시작합니다.
- 결측값이나 경계 상황을 가르치기 위한 값은 의도적으로 포함했음을 본문에서 설명합니다.
- 파일을 수정하면 해당 Chapter의 예제 출력과 분석 문장도 다시 검증합니다.
