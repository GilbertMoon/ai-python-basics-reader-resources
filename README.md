# AI와 함께 배우는 파이썬 기초 — 실습자료

이 저장소는 『AI와 함께 배우는 파이썬 기초』의 독자용 실습자료입니다.

- 도서명: **AI와 함께 배우는 파이썬 기초**
- 부제: **생성형 AI를 개인 튜터로 활용하는 가장 쉬운 파이썬 입문서**
- 지은이: **문길래 (Gilbert Moon)**

책의 예제는 눈으로만 읽기보다 **직접 실행하고, 값을 바꾸고, 오류를 확인하고, 결과를 검증하는 것**을 권장합니다.

## 폴더 구성

```text
examples/     Chapter별 Python 예제 코드
data/         CSV·텍스트 등 실습 데이터
exercises/    별도 파일이 필요한 추가 연습자료
ERRATA.md     정오표
requirements.txt  pandas 등 추가 패키지 목록
```

## 처음 시작하기

Git을 아직 사용하지 않는다면 GitHub 화면에서 **Code → Download ZIP**을 선택해도 충분합니다.

1. ZIP 파일을 내려받아 압축을 풉니다.
2. VS Code에서 압축을 푼 폴더를 엽니다.
3. 책에서 학습 중인 Chapter와 같은 번호의 폴더를 찾습니다.
4. 예제 코드를 실행합니다.
5. 책의 안내에 따라 값이나 조건을 직접 바꾸고 다시 실행합니다.

예를 들어 Chapter 10을 학습한다면 다음 폴더를 사용합니다.

```text
examples/chapter10/
```

## 추가 패키지가 필요한 Chapter

대부분의 기초 예제는 Python 표준 기능만으로 실행할 수 있습니다. pandas 등을 사용하는 뒤쪽 Chapter에서는 가상환경을 활성화한 뒤 다음 명령을 사용할 수 있습니다.

```bash
python -m pip install -r requirements.txt
```

설치가 어려우면 책의 Chapter 15 「모듈·패키지와 가상환경」과 Chapter 21 「데이터 분석과 pandas 시작하기」를 다시 확인하세요.

## 일부 예제는 오류가 정상입니다

오류를 읽고 해결하는 연습을 위해 일부 파일은 의도적으로 오류가 나도록 작성되어 있습니다. 이런 파일에는 다음 표시가 들어 있습니다.

```python
# BOOK_EXPECTED_ERROR
```

해당 파일은 오류 메시지를 확인하는 학습용이므로, 실행 오류가 발생해도 파일이 잘못 배포된 것은 아닙니다.

## AI를 사용할 때

이 책에서 AI는 정답 코드를 대신 작성하는 도구보다 **설명·힌트·디버깅·코드 리뷰를 돕는 개인 튜터**로 사용합니다.

연습문제를 풀 때는 먼저 직접 생각하고, 막히면 다음과 같이 질문해 보세요.

> 나는 파이썬 초보자입니다. 정답 코드를 바로 주지 말고, 내가 먼저 생각할 수 있도록 한 단계의 힌트만 주세요.

AI가 만든 코드도 그대로 믿지 말고 직접 실행해 예상 결과와 비교하세요.
